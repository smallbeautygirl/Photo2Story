## ⏱️ 8-15 分鐘：三個關鍵設計決策

**切到 §2.4、§3.4、§4.3 的流程圖。**

### 決策一：Stage 0 為什麼用混合模式（hybrid）而不是只用 CLIP？（約 2 分鐘）

- 「純 CLIP 只保證**視覺多樣性**，但可能選到跟主題無關的離群值（outlier）」
- 「純 LLM 評分能保**主題相關性**，但 k 張可能都是相似角度」
- 「混合模式 = CLIP 先選 k 張多樣化候選 + LLM 對低分（< 0.4）的圖從候選池替換掉」
- 「兩階段設計避免單一指標的缺陷」

### 決策二：Stage 1 為什麼要兩步式生成？（約 3 分鐘）

- 「直接從照片描述生成故事，LLM 會**逐頁獨立描述**，缺乏因果關係」
- 「**先抽敘事弧（narrative arc）**（起因 → 轉折 → 結束）等同於思維鏈（Chain-of-Thought）」
- 「第二步把敘事弧當劇情骨架，產出 k 頁 JSON 故事」
- 「`use_causal_inference` 是消融實驗的開關，下次會帶比較結果」

### 決策三：Stage 2 為什麼用 SD 1.5 + IP-Adapter？（約 2 分鐘）

- 「**Stable Diffusion 1.5** 用 `diffusers` 套件在本地 GPU 跑」
- 「**IP-Adapter** 讓 SD 除了吃文字提示外，也能吃**風格參考圖**」
- 「對繪本格式很關鍵：**整本書畫風一致**——純文字提示做不到」
- 「VLM 描述用英文當提示（SD 1.5 對非英文提示品質會掉）」

## ⏱️ 15-22 分鐘：🎬 現場演示結果走讀

**切到剛跑完的 `output/demo_<時間戳記>/` 資料夾。**

### 動作順序：

1. **先開 `pages.md`**（用 VSCode 開啟 markdown 預覽）
2. 滾到第 1 頁，指出三個欄位：
   - **VLM description**：「這是 Stage 0 對原始照片的視覺事實描述（英文）」
   - **Page text**：「這是 Stage 1 的故事文字（中文）」
   - **Source photo ↔ Illustration**：「左邊是原始照片，右邊是 SD 生成的插畫」
3. 滾到第 2、3 頁，**強調頁與頁之間的連貫性**：「您看第 2 頁有 reference 到第 1 頁的事件」
4. **最後開 `storybook.pdf`** 給老師看完整繪本
5. 開 `result.json` 給老師看 `narrative` 欄位：「這是兩步式生成抽出來的劇情骨架」

**❗ 如果現場演示失敗 → 立刻開 `output/demo_backup/`（你預先備好的備案）**

### 講的重點：

- 「整本書畫風一致 → IP-Adapter 起作用」
- 「故事頁間有因果連貫 → 因果敘事推論起作用」
- 「選中的 4 張照片涵蓋整個事件 → 混合模式選圖起作用」

## ⏱️ 22-27 分鐘：下次計畫

**切到 [`docs/reports/pipeline_report.md`](pipeline_report.md) 的 §8（下次預計改進方向）。**

### 講的重點（按優先順序）：

1. **下次會議帶來：三組消融實驗的完整對照表**
   - **RQ1（選圖策略）**：隨機 / 純 CLIP / 純 LLM / 混合 四種策略對比
   - **RQ2（主題脈絡利用）**：完整 context / 關鍵字 context 對故事品質的影響
   - **RQ3（因果敘事推論）**：有 / 無 causal inference 對敘事連貫性的差異
   - **格式**：同一頁的逐項並排 + 主觀觀察
2. **中期（約一個月內）：多語系完整支援**
   - PDF 嵌入中日韓（CJK）字體（目前 Helvetica 字體不支援中文）
   - 不同畫風的系統性測試（五大類風格矩陣）
3. **長期：自動化評估框架**
   - 以 LLM 當評審（LLM-as-judge）評故事的連貫性與創意
   - CLIPScore 量插畫-故事對齊度
   - LPIPS 量選圖多樣性

## ⏱️ 27-30 分鐘：問答與決策請教

**這是會議真正有價值的部分，別省略。**

### 主動丟一個選擇題給老師

#### 選項 A（推薦）：評估方式

> 「老師，下次消融實驗結果出來後，**評估方式**我在猶豫：要先用人工 Likert 量表（Likert Scale）評分，還是直接用 LLM 當評審（LLM-as-judge）？前者比較可信但慢，後者快但不知道老師接不接受作為評估指標。」

#### 選項 B：實驗設計優先順序

> 「老師覺得三個研究問題（RQ）哪個優先順序最高？我自己最有興趣的是 RQ3（因果敘事推論），但如果老師覺得 RQ1（選圖策略）對最終品質影響最大，我可以調整下次會議的重點。」

#### 選項 C：技術升級時機

> 「目前 SD 1.5 對非英文提示品質會掉，要不要先升級到 SDXL？這會影響到下次消融實驗的對照基準。」

## 💡 報告小技巧

- **語速放慢**，特別是講設計決策時——教授需要時間消化
- **螢幕分享時鼠標移動慢一點**，每個地方停 2-3 秒
- **現場演示出問題不要慌**，直接切備案：「我這邊有預先跑好的，給老師看」
- **教授問問題就停下來**，不要急著繼續往下講
- **結尾一定要確認**：「老師對下次的交付項目還有沒有其他期待？」
